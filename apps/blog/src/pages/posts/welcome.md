# Welcome to Minions Bundle: Knowledge

We're excited to introduce **Minions Bundle: Knowledge** — Knowledge management bundle — documents, concepts, citations.

## What's Included

- **TypeScript SDK**: `npm install @minions-bundles-knowledge/sdk`
- **Python SDK**: `pip install minions-bundles-knowledge`
- **CLI**: `npm install -g @minions-bundles-knowledge/cli`
