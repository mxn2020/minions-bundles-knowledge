---
title: Installation
description: "Install Minions Bundle: Knowledge packages"
---

## TypeScript / Node.js

```bash
npm install @mxn2020/minions-bundles-knowledge-core minions-sdk
```

## Python

```bash
pip install minions-bundles-knowledge
```

## CLI

```bash
npm install -g @mxn2020/minions-bundles-knowledge-cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
