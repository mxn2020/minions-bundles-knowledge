# Minions Bundle: Knowledge

Knowledge management bundle — documents, concepts, citations

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@mxn2020/minions-bundles-knowledge-sdk`) — Core library for Node.js
- **Python SDK** (`minions-bundles-knowledge`) — Python bindings
- **CLI Tool** (`@mxn2020/minions-bundles-knowledge-cli`) — Command-line interface
- **Web App** — Interactive playground at [app.minions.wtf](https://app.minions.wtf)
